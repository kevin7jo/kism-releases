# 스탁마이너 (StockMiner)

한국투자증권 Open API 기반 주식 자동매매 봇입니다. 웹 브라우저의 **콘트롤타워** 화면에서 전략(레시피)을 만들고, 모의투자로 검증한 뒤 실전으로 전환해 운영합니다.

이 저장소는 스탁마이너의 **릴리즈 안내**입니다. 버전별 변경 내용은 [CHANGELOG](CHANGELOG.md)에서 확인하세요.

## 투자 유의사항

스탁마이너는 사용자가 **자신이 직접 설계한 알고리즘(레시피)** 으로 투자에 참여할 수 있게 해 주는 **도구**입니다. 수익을 자동으로 안겨 주는 상품이 아닙니다. 사용 전에 반드시 아래 내용을 읽고 이해해 주세요.

- 투자에 대한 판단과 그 결과(이익과 손실 모두)는 **전적으로 사용자 본인에게 귀속**됩니다. 투자 원금의 손실이 발생할 수 있습니다.
- 스탁마이너는 **수익을 보장하지 않으며 손실을 막아 주지 않습니다.** 레시피의 매수·매도 조건, 손절·익절 기준, 투자 금액과 대상 종목은 모두 사용자가 정하며, 그에 따른 책임도 사용자에게 있습니다.
- **모의투자, 모의 추출 테스트, 과거 데이터를 바탕으로 한 결과는 실제 수익을 보장하지 않습니다.** 실제 시장에서는 체결 가격, 수수료, 세금, 유동성, 급격한 가격 변동 등으로 결과가 달라질 수 있습니다.
- 함께 제공되는 **기본 레시피와 예시는 사용 방법을 보여 주기 위한 참고 자료**이며, 특정 종목이나 매매를 권유하거나 추천하는 것이 아닙니다.
- 자동매매는 인터넷 연결, 증권사 서버와 API 상태, PC 전원 등 **외부 환경**의 영향을 받아 주문이 지연되거나 실행되지 않을 수 있습니다. 사용자는 계좌와 봇의 상태를 주기적으로 확인해야 합니다.
- 업데이트로 봇의 동작이 달라질 수 있습니다. 새 버전을 적용하기 전에 [변경 이력](CHANGELOG.md)을 확인하고, 필요하면 모의투자로 먼저 점검하세요.

## 주요 기능

- **레시피 기반 전략**: 사용할 지표와 매수·매도 조건을 레시피로 정의합니다. 이동평균, RSI, 볼린저 밴드, MACD, 일목균형표, Supertrend 등 다양한 기술 지표를 조합할 수 있습니다.
- **모의 추출 테스트**: 레시피를 저장하기 전에 오늘 시장에서 어떤 종목이 잡히는지 미리 확인합니다. 실제 주문은 나가지 않습니다.
- **모의투자 / 실전투자 전환**: 같은 전략을 모의투자로 먼저 검증할 수 있습니다.
- **자동 리스크 관리**: 손절, 1차 익절, 트레일링 스탑, 수익 방어 등을 자동으로 처리합니다.
- **시장 상황 필터**: KOSPI·KOSDAQ 지수 추세를 보고 하락장에서는 신규 매수를 제한할 수 있습니다.
- **텔레그램 알림**: 매수·매도 결과와 상태를 알려 줍니다.

## 버전 확인

콘트롤타워 화면 상단 제목 옆의 **버전 배지**에서 현재 버전을 볼 수 있습니다.

## 자동 업데이트 (OTA)

새 버전이 나오면 자동으로 받아 적용할 수 있습니다. **기본값은 꺼져 있으며**, 사용자가 직접 켭니다.

1. 콘트롤타워에서 **🔑 라이선스 관리** 탭을 엽니다.
2. **📡 OTA 자동 업데이트 제어**에서 **자동 업데이트 활성화**를 켭니다.

켜 두면 **매일 새벽 3시**에 새 버전이 있는지 확인하고, 있으면 내려받아 봇이 자동으로 다시 시작됩니다. 장중에는 업데이트하지 않습니다. 끄면 언제든 자동 업데이트를 멈출 수 있습니다.

업데이트 내용은 [CHANGELOG](CHANGELOG.md)에서 미리 확인할 수 있습니다.

## 문제가 생겼을 때

담당자에게 상황을 정확히 알리려면 **진단 파일**을 보내 주세요.

1. 콘트롤타워의 **🔑 라이선스 관리** 탭 아래쪽 **🩺 진단 정보 내보내기**에서 **📥 진단 파일 내려받기**를 누릅니다.
2. 내려받은 `kism_diagnostics_…zip` 파일을 담당자에게 보내 주세요.

진단 파일에는 버전, 라이선스 상태, 봇 동작 상태, 보유 종목과 수익률, 설정 요약, 최근 기록이 들어 있습니다. **계좌번호, API 키, 토큰, 비밀번호는 자동으로 가려져서 담기지 않습니다.** 내가 만든 레시피의 지표와 매수/매도 조건은 기본으로 제외되며, 담당자가 확인이 필요해서 요청할 때만 *레시피 내용도 포함*을 선택해 다시 내려받으면 됩니다. 보내기 전에 압축을 풀어 내용을 직접 확인하셔도 됩니다.

## 보안

- **초기 비밀번호는 첫 로그인 직후 바로 변경하세요.** 콘트롤타워에서는 매매 설정 변경과 긴급 매도가 가능하므로, 초기 비밀번호를 그대로 두면 같은 네트워크의 누구나 접속해 조작할 수 있습니다. 초기 비밀번호를 쓰는 동안에는 화면 맨 위에 경고가 표시되며, **계좌 및 시스템** 탭의 *웹 관제소 보안*에서 변경할 수 있습니다.
- 콘트롤타워 주소(포트)를 공유기에서 인터넷으로 열어 두지 마세요.

## 라이선스

스탁마이너는 라이선스가 등록된 PC에서만 동작합니다. 라이선스는 PC 고유의 하드웨어 지문에 묶이며, 콘트롤타워의 **🔑 라이선스 관리** 탭에서 지문을 확인하고 발급받은 키를 등록합니다.
